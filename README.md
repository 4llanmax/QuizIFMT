## Objetivo

QuizIFMT apresenta o jogo BombQUIZ em PHP, organizado em áreas independentes, com destinos próprios para configuração, dados, arquivos públicos, testes e ferramentas. Este README apresenta o projeto e seu caminho de leitura.
